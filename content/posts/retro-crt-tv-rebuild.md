刷到一条小红书视频：深夜的客厅里，一台奶油色的便携 CRT 电视坐在木柜上，拉杆天线支棱着。一只手拿起旁边的彩色 VHS 卡带，**拖到机身上松手**——屏幕哗地闪过一阵雪花，然后节目画面淡入，荧光绿的频道号在左上角亮起。

就是这个「拖进去」的动作击中了我。它不是点击按钮那种干巴巴的交互，而是一个有重量、有仪式感的拟物动作：取带、拖动、插入、等待雪花退去。于是有了站内灵感档案的 IN-03「复古电视」——本文把这次复刻的设计思路完整摊开。

![奶油机身 CRT 与一摞彩色卡带：本次复刻的灵感场景](/gan/images/posts/crt-blog-cover.jpg)

## 一、质感不是一张贴图，是一份拆解清单

复刻的第一步不是写代码，是把原片里的「复古感」翻译成可执行的样式清单。这台电视的质感来自五个层次，缺一层就「塑料」一分：

1. **机身不是纯色**。奶油外壳用一道 `165°` 的线性渐变铺底——上亮下沉，再用 `inset` 阴影在顶部擦一道高光、在底部压一条暖棕，拟物的体积感全靠这三笔；
2. **屏幕必须凸**。4:3 比例、大圆角、粗黑边框，屏幕内部再叠三层：`radial-gradient` 暗角（CRT 玻璃的边缘收光）、斜切白色半透明条（玻璃反光）、细密横向条纹（扫描线）；
3. **细节要做足**。双拉杆天线带顶端圆球、VOL/CH 两颗旋钮带刻度点、喇叭格栅用 `repeating-linear-gradient` 拉出竖条纹、进带窗是内凹的黑缝；
4. **卡带是第二主角**。彩色壳体 + 白标签（手写频道号和节目名）+ 双带卷窗，四张卡带就是四个频道；
5. **OSD 是灵魂**。荧光绿（`#8f6` 系）等宽字体 + 辉光 `text-shadow`，左上角频道号、右下角 `PLAY 0:12:44`——80 年代电视机的所有记忆点都在这两行小字里。

这些全部是纯 CSS，没有一张机身贴图。好处是机身宽度可以在 `min(560px, 84vw)` 之间自由伸缩，材质不糊、细节不丢。

## 二、交互：把「插卡带」还给手

原片里最动人的就是拖放，所以这是本次复刻的红线——**卡带必须能拖**。用原生 HTML5 Drag & Drop 实现，全程不到六十行：

- 每张卡带是 `draggable` 的按钮，`dragstart` 时把卡带 id 写进 `dataTransfer`；
- 电视机身是投放区：`dragover` 时 `preventDefault` 并点亮高亮——机身描边换成荧光绿、加一圈辉光、微微放大，屏幕中央浮现「**松手插带 ▼**」的 OSD 提示；
- `drop` 时读出卡带 id，插带播放；
- 有个经典小坑：`dragleave` 会在拖拽经过机身子元素时反复触发，高亮会疯狂闪烁。解法是判断 `currentTarget.contains(relatedTarget)`——只有真正离开机身边界才熄灯；
- 触屏浏览器没有原生拖放，所以卡带同时是按钮，**点击兜底插带**。底部提示也写成双通道：「把卡带拖到电视上插放 · 也可以直接点击」。

拖起卡带的一瞬，源卡带缩小变暗——像真的被手提离了卡带架。这些微表情不构成功能，但构成「手感」。

## 三、雪花是仪式感，也是一次架构取舍

插带之后发生什么，决定了这个组件的叙事质量。原片的时序是：**插入 → 雪花闪屏 → 节目登场**。复刻成四段纯 CSS 动画：

- `crt-tape-in`：进带窗里的同色带条落入卡缝——「插进去」的物理确认；
- `crt-snow`：feTurbulence 生成的白噪声图，`steps(4)` 阶梯式抖动 0.55 秒——老电视换台的雪花蹦跳感（平滑缓动就假了）；
- `crt-show`：节目画面延迟 0.5 秒才登场，正好挡住雪花的尾巴，随后 `crt-ken` 以 16 秒周期做 ken-burns 缓动，模拟「正在播放」；
- `crt-osd`：荧光绿频道号分步点亮。

关键的架构决策在这里：**state 只承载交互逻辑（哪张卡带已插入），动画全部留在 CSS 里**。做法是换带时只更新 `loaded` 状态，而画面、雪花、OSD 三组元素的 React `key` 都含卡带 id——id 一变，三组元素重新挂载，CSS 动画自然从头重放。没有一层 JS 计时器，没有一处 `classList` 手术。

这里还踩过一个真实的坑：三组元素是同父兄弟，`key` 全等于卡带 id 时，React 会警告 `Encountered two children with the same key, sunset`。解法是给每组加前缀（`scene-` / `snow-` / `osd-`）——key 的语义是「同组内的身份」，不是「全局身份证」。

最后是降级：所有动效元素挂同一个 `.crt-fx` 类，`prefers-reduced-motion` 下一刀全关，画面由条件挂载保证直接呈现，雪花层基础 `opacity-0` 不残留。

## 四、变体：同一语言的两种再演绎

一比一复刻的原型之外，同一个视觉语言衍生了两个变体，各保留一种交互：

- **遥控换台**：交互从「插卡带」换成「按遥控器」。右侧拟物遥控器数字键 1-4，整个换台引擎是 CSS-only 的 radio 方案——隐藏的 `input[type=radio]` + `label[for]` + 兄弟选择器，选中键点亮为卡带色，零 hooks 零 JS；
- **掌上电视**：横版迷你机身收进掌心，顶部提手、屏幕左置、右列控制键，底部一排迷你卡带——同样可拖可点，交互语言与原型完全同源。

## 五、移动端：小屏上的电视也要能看

复古电视天然是「客厅尺度」的设计，搬进 375px 的手机屏要补三笔：

- 卡带架四张并排，宽度从 `21vw` 收到 `19vw`、间距减半，总宽正好收进机身投影之内，不再溢出舞台；
- 遥控变体的拉杆天线从伸出 80px 缩到 52px——变体舞台块顶部只有 56px 的余量，长出来的部分会被 `overflow-hidden` 无声裁掉；
- 详情页的整屏舞台在小屏改为内部滚动 + 底部避让，超高内容（比如桌面整版的发票工作台）不再被视口上下裁切。

桌面端视觉零变化，所有补偿都发生在 `sm:` 断点以下。

## 结语

复刻不是做仿制品，是做翻译——把一条视频里的材质、动作和节奏，翻译成浏览器能理解的语言。这台电视机最迷人的地方，恰恰不是像素级的相似，而是那个「拖起卡带」的瞬间：**交互的仪式感，比任何滤镜都更接近复古本身**。
